## Important Rules
- **True A/B 필요 시 Mixing Layer(2)만** 사용 — Split Layer(4)로 대체 금지.
- **Eikos 4K Wide Canvas(single_wide)**: Edge-Blending 가로/세로 와이드 PGM(2×4K 믹싱 또는 4 분할) 공식 확인됨. **엔진 판정은 별도 PR 예정.** Pulse 4K에는 이 능력을 복사하지 않는다.
- Mixing / Split / PGM / AUX / Mixer·Matrix·Edge 모드는 서로 다른 개념 — 혼동 금지.
